# Exercícios de Programação Estruturada

Repositório com exercícios e atividades desenvolvidos durante os estudos de **Programação Estruturada**, com foco na prática de fundamentos da programação utilizando principalmente **C e C++**.

O objetivo deste repositório é registrar minha evolução no desenvolvimento de algoritmos e na utilização de estruturas fundamentais da programação.

## 📚 Conteúdos abordados

Entre os principais conceitos praticados estão:

* Variáveis e tipos de dados
* Estruturas condicionais
* Estruturas de repetição
* Funções e procedimentos
* Vetores e matrizes
* Strings
* Ponteiros
* Structs
* Manipulação de arquivos
* Busca e manipulação de dados
* Estruturas de dados básicas
* Resolução de problemas por meio de algoritmos

## 🛠️ Tecnologias

* **C**
* **C++**
* GCC / compiladores compatíveis
* Git e GitHub

## 📂 Organização

O repositório contém diferentes exercícios e atividades desenvolvidos ao longo da disciplina, incluindo exemplos relacionados a:

* `vetores` — exercícios envolvendo vetores e operações sobre seus elementos
* `strings` — manipulação e processamento de strings
* `ponteiros` — utilização de ponteiros e operações com memória
* `structs` — criação e manipulação de estruturas
* `arquivos` — leitura e escrita de arquivos
* `atividades` — exercícios propostos durante a disciplina

Os arquivos são independentes e representam diferentes exercícios e práticas realizadas durante o processo de aprendizagem.

## 🎯 Objetivos de aprendizagem

Este repositório foi desenvolvido com o objetivo de consolidar conhecimentos fundamentais que servem de base para disciplinas e projetos posteriores, especialmente:

* Raciocínio lógico e resolução de problemas
* Desenvolvimento de algoritmos
* Gerenciamento e manipulação de memória
* Organização de dados
* Implementação de soluções em baixo nível
* Desenvolvimento de código em C e C++

## 🚀 Como executar

Para executar os exercícios, é necessário possuir um compilador compatível com C ou C++.

### C

```bash
gcc arquivo.c -o programa
./programa
```

### C++

```bash
g++ arquivo.cpp -o programa
./programa
```

No Windows, o programa compilado pode ser executado através do terminal ou de uma IDE compatível.
